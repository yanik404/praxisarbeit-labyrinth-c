# Praxisarbeit Labyrinth C

Textbasiertes Konsolenspiel in C für die Praxisarbeit Programmiertechnik.

## Spiel
- `P` = Spieler
- `T` = Schatz
- `O` = Hindernis
- Steuerung mit `W`, `A`, `S`, `D`
- Beenden mit `Q`

## Kompilieren
```bash
gcc main.c -o labyrinth -Wall -Wextra -Wpedantic
```

## Starten
Windows:
```powershell
.\\labyrinth.exe
```

Linux/macOS:
```bash
./labyrinth
```
